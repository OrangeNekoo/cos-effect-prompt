# GPT Image 2.5 编辑提示词要点

GPT Image 2.5 是 OpenAI 的图像生成与编辑模型系列。它适合接收原图和具体、可观察的自然语言编辑要求：明确要改什么、改在哪里、改成什么样，同时明确哪些内容必须保持不变。

## 核心原则

1. **先写动作和区域**：使用添加、移除、替换、修复、重塑等强动词，说明作用区域和前景/中景/背景关系。
2. **保持人物身份**：默认保持面部特征、发型、服装版型与图案、动作姿势、构图和背景，除非用户明确要求修改。
3. **保持空间关系**：新增元素匹配原图的灭点、相机角度、地面透视、遮挡关系和景深。
4. **描述可见结果**：具体写颜色、材质、边缘、透明度、运动方向、反射和光照，不用空泛的“高级”“更好看”。
5. **统一融合**：新增内容与原图的光影方向、色温、反射、高光、阴影、噪点和颗粒一致。
6. **局部编辑优先**：用户只要求局部变化时，不要扩展成全局调色、重绘人物或替换背景。

## 推荐结构

```text
编辑这张照片：在[区域]添加/修改[对象]。
目标外观：[颜色、材质、形状、细节、强度]。
空间关系：[透视、遮挡、景深、运动方向]。
融合要求：[光影、反射、色温、噪点、边缘]。
保持不变：[面部、发型、服装、姿势、构图、背景等]。
```

## Responses API 边界

Responses API 的图像生成工具可以使用 GPT Image 2.5 作为工具模型，例如 `gpt-image-2.5-sunburst` 或 `gpt-image-2.5-flare`；这与本项目当前 Photoshop 插件的职责不同。

本项目插件按原有工作流调用用户填写的 Responses API 文本/视觉驱动模型，生成供 GPT Image 2.5 使用的提示词预设。它发送：

- `POST <API 根地址>/responses`
- `instructions`：技能规则和用户知识库
- `input`：文本历史或 `input_image` 图片输入
- `Authorization: Bearer <用户自己的 Key>`

插件当前不直接调用 `image_generation` 工具，不下载图像结果，也不创建 Photoshop 图层。GPT Image 2.5 是提示词目标模型；顶层 Responses 驱动模型应填写你的服务商实际支持的模型名，例如 `gpt-4.1`。

## 编辑示例

```text
编辑这张 COS 人像照片：只在人物脚下地面添加一个金色发光魔法阵。魔法阵贴合地面透视，近处略宽、远处略窄，符文清晰但不过曝；金色光线自然反射到鞋面和腿部。保持人物的脸、发型、服装、动作、构图和背景不变，不要残留红色标记。
```

## 与旧 Nano Banana 名称的关系

仓库中的 `references/nano-banana.md` 和旧配置值 `nanobanana` 为历史兼容内容。用户仍说“Nano Banana”或“Gemini 图像”时，默认按 GPT Image 2.5 的自然语言编辑规则生成新的 `gptimage` 目标格式。
